## 统一技术口径

- 向量与矩阵用粗体（`\mathbf{o}`、`\mathbf{W}` 等），标量保持细体（`D`、`n`、`\epsilon_0`、`t` 以及坐标分量 `b_i`）。
- 使用 `\mathbf{r} = \mathbf{o} - \mathbf{c}`，维度记为 `D`，并显式区分原坐标与旋转坐标 `\mathbf{z} = \mathbf{W}\mathbf{r}`。
- 1-bit 量化向量用单个符号 `\mathbf{u}` 表示，避免 `bf` 被读成两个向量的乘积。
- 不以 `\mathbf{r} ≈ α\mathbf{u}` 和“量化能量守恒”推导距离；保留精确的 `‖r‖²`，
  仅使用比值估计器估计交叉内积。交叉项由单位残差内积
  `⟨ẑ, ŷ⟩ ≈ ⟨u, ŷ⟩ / ⟨u, ẑ⟩` 推出
  `⟨q-c,r⟩ ≈ ‖r‖² ⟨W(q-c),u⟩ / ⟨Wr,u⟩`（文中对应符号均为粗体向量/矩阵）。
- 将 `‖r‖² / ⟨Wr,u⟩` 描述为内积估计的比例修正，而不是一个独立的
  “无偏重构标量”。
- 默认快速旋转描述为四轮随机符号翻转、FWHT 与非 2 次幂维度下的 Kac mixing；
  同时说明可选的稠密随机正交矩阵模式。
- 完整 L2 误差半径写为数据侧 `error_factor` 与查询侧 `‖q-c‖` 的乘积，
  并明确它是来自 RaBitQ 理论的高概率界，而不是确定性界。
- 在公式中标出离线（Indexing）与在线（Online）：`add`/`scale`/`error` 为每行离线项，
  `query`/`query_error` 为每查询×分区在线项，`⟨Wq,u⟩` 为每候选交互项。
  `add` 含质心交叉项，不等于单独的 `‖r‖²`。
- 说明 Lance 当前把下界剪枝用于满足条件的多比特 `IVF_RQ` 分区扫描，
  不宣称当前已用于 HNSW 图搜索，也不把该下界写成确定性三区域剪枝。
- 多比特码描述为对称半整数网格加逐向量自适应缩放，不称为固定范围上的
  普通均匀标量量化。
- “training-free”仅指 RQ 量化器；`IVF_RQ` 整体仍需要 IVF 聚类中心。
- “32 倍”仅作为 1-bit code 相对 float32 payload 的理论值，并说明索引辅助列开销。
