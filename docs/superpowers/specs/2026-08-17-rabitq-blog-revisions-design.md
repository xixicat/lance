# RaBitQ 博文三版本修订设计

## 目标

基于 Lance 提交 `e1dbd14288b40cc4f83264328bbc336f4c697dc9` 的实现，以及 RaBitQ
论文和官方参考库，生成三份可独立发布的中文 Markdown 博文。三稿面向不同读者，
但采用一致的数学符号、源码事实和外部资料口径。

## 交付物

1. `lance-rabitq-original-style.md`
   - 保留原稿五章结构、叙事节奏和较强的技术文章风格。
   - 改正距离估计器、旋转坐标系、误差界、多比特编码和剪枝范围。
   - 删除无法由源码或公开基准支持的具体概率、I/O 和吞吐数字。
2. `lance-rabitq-source-analysis.md`
   - 作为推荐主稿，以源码执行路径重新组织内容。
   - 结构为：背景、旋转、1-bit 编码、距离估计、误差界、多比特增量估计、
     查询与剪枝路径、工程权衡、结论。
   - 清楚区分论文保证、参考库设计和 Lance 当前实现。
3. `lance-rabitq-introduction.md`
   - 面向普通开发者的短篇版本。
   - 只保留理解算法所需的关键公式，突出“为什么旋转、如何估距、界如何使用”。
   - 避免实现细节淹没主线。

## 统一技术口径

- 使用 `r = o - c`，并显式区分原坐标与旋转坐标 `z = Wr`。
- 不以 `r ≈ αbf` 和“量化能量守恒”推导距离；保留精确的 `‖r‖²`，
  仅使用比值估计器估计交叉内积。
- 将 `‖r‖² / ⟨Wr,bf⟩` 描述为内积估计的比例修正，而不是一个独立的
  “无偏重构标量”。
- 默认快速旋转描述为四轮随机符号翻转、FWHT 与非 2 次幂维度下的 Kac mixing；
  同时说明可选的稠密随机正交矩阵模式。
- 完整 L2 误差半径写为数据侧 `error_factor` 与查询侧 `‖q-c‖` 的乘积，
  并明确它是来自 RaBitQ 理论的高概率界，而不是确定性界。
- 说明 Lance 当前把下界剪枝用于满足条件的多比特 `IVF_RQ` 分区扫描，
  不宣称当前已用于 HNSW 图搜索。
- 多比特码描述为对称半整数网格加逐向量自适应缩放，不称为固定范围上的
  普通均匀标量量化。
- “training-free”仅指 RQ 量化器；`IVF_RQ` 整体仍需要 IVF 聚类中心。
- “32 倍”仅作为 1-bit code 相对 float32 payload 的理论值，并说明索引辅助列开销。

## 引用与可验证性

- 文中引用源码时使用仓库相对路径与函数名，避免绑定易漂移的绝对行号。
- 附上审阅提交哈希和 RaBitQ 论文、RaBitQ-Library estimator 文档链接。
- 不写入“千万分之一漏召回”“80% I/O 剪枝”等缺少可复现实验的数据。
- 三稿完成后检查 Markdown 标题、代码块、LaTeX 定界符、内部术语一致性和
  未完成占位符。

## 范围
